OCR et Analyse d’images

Tesseract OCR (pour extraire le texte des images)

Installer Tesseract : https://github.com/tesseract-ocr/tesseract

Ajouter tesseract.exe au PATH.

Installer la bibliothèque Python : pip install pytesseract
Analyse de sentiment

Tu peux utiliser TextBlob ou transformers :

pip install textblob
python -m textblob.download_corpora
# ou si tu veux un modèle Hugging Face pour sentiment :
pip install transformers torch
